# Spy-Station 🛰️🕵️

لعبة **محطة الجواسيس (Spy Station)** - لعبة جماعية تفاعلية ذكية متعددة اللاعبين (Multiplayer) لكشف الجاسوس بالاعتماد على الفراسة والذكاء والتحليل.

## ✨ المميزات الرئيسية (Features)
- 🚀 **غرف لعب عامة وخاصة (Public & Private Stations):** مشاركة كود التردد أو الانضمام للمحطات العامة مع نظام طابور وموافقة منظمة من قائد المحطة (Host).
- 🎭 **أطوار لعب متعددة (Game Modes):**
  - **الطور الكلاسيكي (Classic):** تلميحات بالدور وتصويت ذكي.
  - **شبكة العملاء (Mole Network):** الجواسيس يعرفون بعضهم وينسقون سراً عبر شات خاص.
  - **المحطة الصامتة (Silent Drawing):** رسم تلميحات مباشرة على رادار تفاعلي دون كلام.
  - **بطاقات التخريب (Sabotage Cards):** بطاقات الحصانة، تبديل الأدوار، وإعادة التصويت الإجباري.
- 🖼️ **مكتبة بصرية ذكية متكاملة (Visual Word Cards):** صور دقيقة وتوضيحية لكل كلمة في كافة الفئات (اللاعبين، الأكل، الألعاب، الحيوانات، الأفلام والمسلسلات، المغنيين، والأماكن).
- 👥 **نظام أصدقاء وحسابات متكامل:**
  - إضافة الأصدقاء بكود الصداقة الفريد ومتابعة حالتهم (Online / Offline).
  - إرسال دعوات مباشرة لدخول المحطة بنقرة واحدة.
  - تحديث فوري للاسم والصورة الشخصية لدى جميع الأصدقاء وفي الرومات مباشرة.
  - إمكانية تسجيل الدخول عبر Google أو بالبريد وكلمة المرور بكل سلاسة.
- 📱 **دعم تثبيت التطبيق (PWA):** تثبيت اللعبة كتطبيق أصلي على الهواتف والأجهزة مع دعم كامل للشاشات باللغتين العربية والإنجليزية.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend & Realtime:** Firebase Realtime Database & Firebase Authentication
- **Icons & Audio:** Lucide React & Web Audio API Synthesizer
- **PWA:** Vite Plugin PWA & Service Workers

## 🚀 التشغيل المحلي (Getting Started)
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
